# Баримт ба JSON байршуулах заавар

## 1. Анхны DOCX/PDF хаана оруулах вэ?
- `data/source_docs/` — компанийн анхны DOCX, PDF, TXT баримт. Нэг баримтыг өөрчлөхгүй хадгална.
- `data/documents/` — эх баримтаас гараар хянаж, бүтцэд оруулсан JSON. `status: draft` хэвээр байлгана.
- `data/fixtures/` — зохиомол туршилтын өгөгдөл; production-д ашиглахгүй.
- `data/golden_set/` — асуулт ба хүлээгдэж буй үр дүн; энэ нь knowledge source биш.

## 2. Алхам
1. DOCX/PDF-ээ `data/source_docs/` дотор хуул.
2. Баримтын өгүүлбэрийг өөрчлөлгүй эсвэл хянан засаж `data/documents/<category>.json` дотор sections болгон оруул.
3. `source_name`-ийг эх файлын нэртэй тааруул. `page`-ийг бодит хуудастай үед бөглө; үгүй бол `null`.
4. Баталгаажаагүй зүйлд `draft` хэрэглэ. Хуурамч жишээг `test_only` болгож тусгаарла.
5. `python scripts/validate_documents.py` ажиллуул.
6. Эрх бүхий хүн агуулгыг хянасны дараа л `approved` болгоно.

## 3. Production retrieval
Зөвхөн `status=approved`, хүчинтэй огноотой баримт indexing болон retrieval-д орно. Ноорог файлуудыг production индексэд оруулахгүй. Сургалтын үнэ, хуваарь, хэрэглэгчийн төлөв зэрэг динамик мэдээллийг үндсэн backend API-аас авна.

## 4. Бусад
`doc_type` зөвшөөрөгдөх утга: `company`, `service`, `course`, `faq`, `policy`. `course_id` нь зөвхөн тодорхой сургалтад хамаарах үед утгатай. `page=null` бол веб эх сурвалж эсвэл хуудасгүй баримт гэсэн үг.
